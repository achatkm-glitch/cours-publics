Transport : advection et diffusion d'une gaussienne

Solution exacte de ct + a cx = D cxx pour une gaussienne initiale : le centre se déplace (advection), la largeur croît (diffusion). Séance 1, bloc A. Chaque paramètre a un curseur ; le champ placé dessous accepte d'autres valeurs (séparées par des espaces) pour superposer jusqu'à six courbes.

Repère : avec a = 1, D = 0,05 et σ₀ = 0,15, à t = 4 : centre 4, σ = 0,65, pic 0,2308 ; nombre de Péclet |a|σ₀/D = 3.

Barre : conditions aux limites Dirichlet, Neumann, Robin

Conduction stationnaire λ T'' + q = 0 avec T(0) = T₀ imposée et trois conditions possibles en x = L. Séance 1, bloc B. Cochez plusieurs conditions pour les comparer ; par défaut, l'exemple de la paroi du polycopié où elles sont équivalentes.

Repère (valeurs initiales) : C₁ = 810 K/m, T(L) = 331 K, T max ≈ 332,8 K en x = 0,081 m ; flux sortants 8100 W/m² en x = 0 et 1900 W/m² en x = L, dont la somme vaut q·L = 10 000 W/m².

Barre 1D : différences finies et volumes finis

Résout λ T'' + q = 0 avec T(0) = T₀ et T(L) = T_L sur N intervalles, par le schéma centré aux nœuds (différences finies) et par un bilan sur N cellules (volumes finis). Séance 1, bloc C. Les deux graphiques montrent la solution et son erreur par rapport à la solution analytique ; le champ sous le curseur de N accepte d'autres valeurs (par exemple 8 16) pour comparer les maillages.

Repère : N = 4, T₀ = 300 K, T_L = 400 K, q = 0 : les deux schémas sont exacts (solution affine). Avec q = 100 W/m³ (λ = 1, L = 1) : les différences finies restent exactes (solution quadratique) ; les volumes finis ont une erreur de 0,78 K (N = 4) puis 0,20 K (N = 8), divisée par 4 quand N double (ordre 2). Le bilan de flux est exact en volumes finis (schéma conservatif) et vaut −q·h en différences finies.

Péclet : convection–diffusion en volumes finis

Résout ρu φ' = Γ φ'' sur [0,1] avec φ(0) = 0 et φ(1) = 1, en volumes finis sur N cellules, avec deux reconstructions de la valeur convectée aux faces : centrée et amont. Pe = ρuL/Γ est le nombre de Péclet global et Pe_h = Pe/N celui de la maille. Séance 1, bloc A (nombre de Péclet). Comparez les schémas et superposez plusieurs maillages.

Repère : avec Pe = 50 et N = 10 (Pe_h = 5), le schéma centré oscille (minimum −1,50) alors que l'amont reste monotone (erreur 0,20). Le centré cesse d'osciller à partir de N = 25 (Pe_h ≤ 2). Pour N = 100, le centré (erreur 0,029) est plus précis que l'amont (0,069).

Jacobi et Gauss–Seidel

Résout −u'' = f sur [0,1] avec u(0) = u(1) = 0 et n nœuds intérieurs (h = 1/(n+1)), à partir du vecteur nul. Séance 2, exercice C. Les deux méthodes sont comparées sur les mêmes graphiques.

Repère (n = 5, f = 1) : Jacobi, u⁽¹⁾ = 1/72 partout ; u⁽²⁾ = (1/48, 1/36, 1/36, 1/36, 1/48). Gauss–Seidel, u⁽²⁾ = (7/288, 11/288, 53/1152, 29/576, 5/128). Solution exacte (5/72, 1/9, 1/8, 1/9, 5/72).

Ordre d'une différence finie

Erreur en x = 0 de trois différences finies pour u(x) = exp(x), pour une suite de pas : progressive, centrée et régressive à trois points. Séance 2, exercice D.

Repère : progressive, 5,171×10⁻² puis 2,542×10⁻² (rapport 2) ; centrée, 1,667×10⁻³ puis 4,167×10⁻⁴ (rapport 4).

Fermetures de Neumann d'ordre 1 et 2

Résout −u'' = cos x sur [0,1] avec u(0) = 1 et u'(1) = 1 − sin 1 (solution exacte cos x + x). Compare la fermeture d'ordre 1 (u_N = u_{N−1} + h g) et celle d'ordre 2 (différence régressive à trois points). Séance 2, exercice H.

Repère : pour N de 10 à 80, l'ordre global observé vaut environ 1,0 avec la fermeture d'ordre 1 et environ 2,0 avec celle d'ordre 2.

Chaleur 1D : FTCS, BTCS, Crank–Nicolson

Résout u_t = α u_xx sur [0,L] avec u = 0 aux bords et u(x,0) = sin(πx/L), jusqu'au temps final. Compare les schémas sur les mêmes graphiques et plusieurs pas de temps dans le tableau et le second graphique. Séance 3, exercices A et D.

Repère : avec α = 10⁻⁵ m²/s, L = 0,10 m, h = 5 mm, Δt = 1 s et FTCS : Fo = 0,4, valeur centrale 0,990151 après un pas, contre 0,990179 pour la solution exacte ; pas de temps maximal 1,25 s. Avec un temps final de 200 s et Δt = 2 s (Fo = 0,8), FTCS devient instable alors que BTCS et Crank–Nicolson restent précis.

Chemin de raffinement Δt = c₀ hʳ

Évalue le terme décisif du défaut local de Dufort–Frankel, α(Δt/h)², et de Lax–Friedrichs, h²/(2Δt), le long de plusieurs chemins. Séance 3, exercices C et E. Le champ sous le curseur de r accepte d'autres exposants pour les comparer.

Repère : Dufort–Frankel est consistant avec la diffusion si Δt/h → 0, soit r > 1 ; Lax–Friedrichs est consistant avec l'advection si et seulement si 0 < r < 2. Pour r = 2, le terme de Lax–Friedrichs reste constant et le schéma approche u_t + a u_x = u_xx/(2c₀).

Un terme qui ne tend pas vers zéro quand h diminue signale une consistance perdue sur ce chemin.

Advection d'une gaussienne

Résout u_t + a u_x = 0 sur le domaine périodique [−2, 8] avec une gaussienne initiale (σ₀ = 0,15, amplitude 1). Superpose amont, FTCS centré, Lax–Friedrichs et Lax–Wendroff ; le tableau compare plusieurs maillages. Séance 3, exercice G.

Repère : avec Co = 0,4 et Nx = 100 ou 200, FTCS centré est instable (amplitude croissante), l'amont et Lax–Friedrichs lissent le profil (diffusion numérique), Lax–Wendroff produit des oscillations (dispersion). Avec Co > 1, l'amont devient instable à son tour. La vitesse a doit être non nulle ; pour a < 0 le schéma amont prend la différence du côté opposé.
