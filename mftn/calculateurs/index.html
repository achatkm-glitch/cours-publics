Introduction : pourquoi le choix du schéma compte

Un même signal, une bosse lisse et un créneau, est transporté à vitesse constante sur un domaine périodique : après un tour entier, la solution exacte est identique au signal initial. Chaque schéma le déforme pourtant à sa façon. Test classique inspiré de la figure 6.1 de LeVeque (2002) ; les paramètres sont ceux de ce site. Introduction du cours, séance 1.

Repère : avec N = 100 et C = 0,8, l'amont lisse la bosse (pic 0,745 après 1 tour, 0,449 après 5) sans oscillation ; Lax–Wendroff et Beam–Warming conservent mieux la bosse (0,978 ; 0,991) mais oscillent (minimum −0,175 ; −0,256). FTCS centré explose. Pour C = 1, les quatre schémas à stencil amont ou centré sont exacts.

Transport : advection et diffusion d'une gaussienne

Un profil gaussien est transporté par la vitesse a et étalé par la diffusion D. Les courbes montrent le centre qui se déplace, la largeur qui croît et l'aire conservée ; la jauge donne le nombre de Péclet, qui compare les deux effets. Séance 1, bloc A. Chaque paramètre a un curseur ; le champ placé dessous accepte d'autres valeurs (séparées par des espaces) pour superposer jusqu'à six courbes.

Repère : avec a = 1, D = 0,05 et σ₀ = 0,15, à t = 4 : centre 4, σ = 0,65, pic 0,2308 ; nombre de Péclet |a|σ₀/D = 3.

EDP : classer une équation et lire son comportement

Le signe du discriminant des coefficients du terme d'ordre 2 donne le type de l'EDP, donc la façon dont l'information se propage et les données à fournir. Réglez A, B et C pour passer d'un type à l'autre ; la courbe tracée est la conique associée. Le dernier curseur suit un cas non linéaire dont le type change avec la solution. Séance 1, bloc B.

Repère : A = 1, B = 0, C = 4 donne Δ = −4 (elliptique). Pour la chaleur u_t − α u_xx, on a A = −α, B = 0, C = 0 : Δ = 0 (parabolique). Pour l'onde u_tt − c² u_xx, A = −c², B = 0, C = 1 : Δ = c² > 0 (hyperbolique).

EDP : comportement des trois types

Chaque type a son comportement : une EDP elliptique décrit un équilibre où toute la frontière influence chaque point ; une EDP parabolique diffuse et lisse, avec une propagation instantanée mais très faible loin de la source ; une EDP hyperbolique propage l'information à vitesse finie, dans un cône de dépendance. Choisissez un type et jouez avec les curseurs. Séance 1, bloc B.

Repère : avec le côté gauche à 100 °C et les trois autres à 0 °C, la température au centre vaut 25 °C ; avec deux côtés opposés à 100 °C, 50 °C ; avec trois côtés à 100 °C, 75 °C.

Repère : avec D = 0,05, deux sources en x = ±2 et t = 2 : σ = 0,4717 ; la valeur en x = 5 est non nulle (5,2e-10) mais minuscule.

Repère : avec c = 1 et t = 2, la bosse initiale se sépare en deux impulsions d'amplitude 0,5 situées en x = ±2 ; en x = 3, hors du cône, la valeur est nulle (1e-10).

Barre : conditions aux limites Dirichlet, Neumann, Robin

Conduction stationnaire dans une barre avec production, la température étant imposée en x = 0 et trois conditions possibles en x = L. Séance 1, bloc B. Cochez plusieurs conditions pour les comparer ; par défaut, l'exemple de la paroi du polycopié, où elles sont équivalentes.

Repère (valeurs initiales) : C₁ = 810 K/m, T(L) = 331 K, T max ≈ 332,8 K en x = 0,081 m ; flux sortants 8100 W/m² en x = 0 et 1900 W/m² en x = L, dont la somme vaut q·L = 10 000 W/m².

Barre 1D : différences finies et volumes finis

Même problème traité par le schéma centré aux nœuds (différences finies) et par un bilan sur N cellules (volumes finis). Séance 1, bloc C. Les deux graphiques montrent la solution et son erreur par rapport à la solution analytique ; le champ sous le curseur de N accepte d'autres valeurs (par exemple 8 16) pour comparer les maillages.

Repère : N = 4, T₀ = 300 K, T_L = 400 K, q = 0 : les deux schémas sont exacts (solution affine). Avec q = 100 W/m³ (λ = 1, L = 1) : les différences finies restent exactes (solution quadratique) ; les volumes finis ont une erreur de 0,78 K (N = 4) puis 0,20 K (N = 8), divisée par 4 quand N double (ordre 2). Le bilan de flux est exact en volumes finis (schéma conservatif) et vaut −q·h en différences finies.

Péclet : convection–diffusion en volumes finis

Convection–diffusion stationnaire entre deux valeurs imposées, résolue en volumes finis sur N cellules avec deux reconstructions de la valeur convectée aux faces : centrée et amont. Pe est le nombre de Péclet global et Pe_h celui de la maille. Séance 1, bloc A. Comparez les schémas et superposez plusieurs maillages.

Repère : avec Pe = 50 et N = 10 (Pe_h = 5), le schéma centré oscille (minimum −1,50) alors que l'amont reste monotone (erreur 0,20). Le centré cesse d'osciller à partir de N = 25 (Pe_h ≤ 2). Pour N = 100, le centré (erreur 0,029) est plus précis que l'amont (0,069).

Jacobi et Gauss–Seidel

Un système tridiagonal issu de la discrétisation de la diffusion 1D est résolu par Jacobi et par Gauss–Seidel, à partir du vecteur nul. Séance 2, exercice C. Les deux méthodes sont comparées sur les mêmes graphiques.

Repère (n = 5, f = 1) : Jacobi, u⁽¹⁾ = 1/72 partout ; u⁽²⁾ = (1/48, 1/36, 1/36, 1/36, 1/48). Gauss–Seidel, u⁽²⁾ = (7/288, 11/288, 53/1152, 29/576, 5/128). Solution exacte (5/72, 1/9, 1/8, 1/9, 5/72).

Ordre d'une différence finie

Erreur en x = 0 de trois différences finies pour la fonction exponentielle, pour une suite de pas. Séance 2, exercice D.

Repère : progressive, 5,171×10⁻² puis 2,542×10⁻² (rapport 2) ; centrée, 1,667×10⁻³ puis 4,167×10⁻⁴ (rapport 4).

Fermetures de Neumann d'ordre 1 et 2

Problème avec une condition de Dirichlet à gauche et une condition de Neumann à droite, de solution exacte connue. Compare la fermeture d'ordre 1 et celle d'ordre 2. Séance 2, exercice H.

Repère : pour N de 10 à 80, l'ordre global observé vaut environ 1,0 avec la fermeture d'ordre 1 et environ 2,0 avec celle d'ordre 2.

Chaleur 1D : FTCS, BTCS, Crank–Nicolson

Un profil sinusoïdal se refroidit entre deux bords à température nulle. Compare les schémas sur les mêmes graphiques, et plusieurs pas de temps dans les cartes et le second graphique. Séance 3, exercices A et D.

Repère : avec α = 10⁻⁵ m²/s, L = 0,10 m, h = 5 mm, Δt = 1 s et FTCS : Fo = 0,4, valeur centrale 0,990151 après un pas, contre 0,990179 pour la solution exacte ; pas de temps maximal 1,25 s. Avec un temps final de 200 s et Δt = 2 s (Fo = 0,8), FTCS devient instable alors que BTCS et Crank–Nicolson restent précis.

Chemin de raffinement Δt = c₀ hʳ

Évalue le terme décisif du défaut local de Dufort–Frankel et de Lax–Friedrichs le long de plusieurs chemins de raffinement. Séance 3, exercices C et E. Le champ sous le curseur de r accepte d'autres exposants pour les comparer.

Repère : Dufort–Frankel est consistant avec la diffusion si Δt/h → 0, soit r > 1 ; Lax–Friedrichs est consistant avec l'advection si et seulement si 0 < r < 2. Pour r = 2, le terme de Lax–Friedrichs reste constant et le schéma approche u_t + a u_x = u_xx/(2c₀).

Un terme qui ne tend pas vers zéro quand h diminue signale une consistance perdue sur ce chemin.

Advection d'une gaussienne

Une gaussienne est transportée sur un domaine périodique. Superpose amont, FTCS centré, Lax–Friedrichs et Lax–Wendroff ; les cartes comparent plusieurs maillages. Séance 3, exercice G.

Repère : avec Co = 0,4 et Nx = 100 ou 200, FTCS centré est instable (amplitude croissante), l'amont et Lax–Friedrichs lissent le profil (diffusion numérique), Lax–Wendroff produit des oscillations (dispersion). Avec Co > 1, l'amont devient instable à son tour. La vitesse a doit être non nulle ; pour a < 0 le schéma amont prend la différence du côté opposé.

Premier jet : vérification technique seulement. Les valeurs de repère proviennent du polycopié MFTN, sauf les itérations de Jacobi et de Gauss–Seidel, les ordres globaux de Neumann, le pas FTCS, l'exemple de la gaussienne, les volumes finis de la barre et la convection–diffusion, calculés par le rédacteur et contrôlés par les tests (test_calc.js).
